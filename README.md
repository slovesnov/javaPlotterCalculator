Expression parser is parser of strings like *sin(pi/4)* which is realized on c++, javascript, java, php languages. You can create functions *x0+2\*sin(pi\*x1)* for further calculations also with the list of variables *ExpressionEstimator("a+2\*b", "a", "b")*. The projects scientific calculator and graph plotter were created on the basis of the parser.

Parser description [https://slovesnov.rf.gd?parser](https://slovesnov.rf.gd?parser).

The source code is split into several repositories
<br>[c++ parser](https://github.com/slovesnov/parser_cpp)
<br>[c++/gtk3 calculator](https://github.com/slovesnov/calculator), the [aslov](https://github.com/slovesnov/aslov) library is used
<br>[c++/gtk3 plotter](https://github.com/slovesnov/graph), the [aslov](https://github.com/slovesnov/aslov) library is used
<br>[java parser/calculator/plotter](https://github.com/slovesnov/javaPlotterCalculator)
<br>[js/php](https://github.com/slovesnov/parser) parser js, php and js calculator/plotter

Парсер выражений - это разборщик строк типа *sin(pi/4)* реализованный на c++, javascript, java, php. Можно создавать функции *x0+2\*sin(pi\*x1)* для дальнейших вычислений в том числе и с заданием списка переменных *ExpressionEstimator("a+2\*b", "a", "b")*. На основе парсера созданы проекты научный калькулятор и построитель графиков.

Описание парсера [https://slovesnov.rf.gd?parser,ru](https://slovesnov.rf.gd?parser,ru).

Исходный код разбит на несколько репозиториев
<br>[c++ парсер](https://github.com/slovesnov/parser_cpp)
<br>[c++/gtk3 калькулятор](https://github.com/slovesnov/calculator), используется библиотека [aslov](https://github.com/slovesnov/aslov)
<br>[c++/gtk3 плоттер](https://github.com/slovesnov/graph), используется библиотека [aslov](https://github.com/slovesnov/aslov)
<br>[java парсер/калькулятор/плоттер](https://github.com/slovesnov/javaPlotterCalculator)
